# 典拠調べの依頼（ひな形）

**学派ごとの典拠の回で、調べ役（サブエージェント）に渡す依頼文のひな形である。**
現象学と実存の回の依頼文（もと `tools/_work/phe_agent_brief.md`）を、2026年9月24日にここへ移した。

## 使い方

1. このファイルを `tools/_work/<棚の略号>_agent_brief.md` へ写す（写しは作業用なので Git に入れない）
2. **`{{…}}` の5か所だけを書き換える。**それ以外の文は変えない
   - `{{棚}}` … 学派名（例：フランクフルト学派）
   - `{{原典の箇所の例}}` … その棚で本文が指しがちな原典の箇所（全集の巻と頁、主著の章・節など）
   - `{{公有の原典}}` … その棚で公有と分かる著者と、その原典の正規の公開元。**著者の没年と刊行年から決める**（CLAUDE.md「探し先を選ぶ前に、著者の没年を見る」）
   - `{{全文サイトを使わない著者}}` … 原典がまだ公有でない著者（全文を載せたサイトを使わない）
   - `{{この棚で特に見ること}}` … その棚で出回りやすい引用・伝記の事実・共著の分担など、利用者がその回に挙げた見どころ。無ければ「なし」
3. 書き換えた写しを、調べ役への指示の最初に読ませる

**共通の部分（基準の典拠、使わないもの、アクセス制限をよけない一文、返答の形）を直すときは、このひな形を直す。**
写しだけを直すと、次の回に戻らない。

# 典拠調べの依頼（{{棚}}の回）

**原則：権利者が機械での取得や抽出を制限している設定は、形を問わず越えない。迷ったら取らずに報告する。**（下の「アクセス制限をよける取得はしない」とその例、PDF の設定の確かめ方は、この原則の具体例である）

あなたは調べ役です。**ファイルは一切書き換えないこと**（読むのは自由）。結果は最後の返答に書く。
**作業用のファイル（取ったページや PDF）は、scratchpad の中に自分専用のフォルダを作ってそこに置く。**ほかの調べ役が同時に動いており、同じ名前のファイルを上書きし合うことがある（2026年9月25日、精神分析の回で起きた）。

**アクセス制限をよける取得はしない。開けなければ開けなかったと書く。**これは最初に守ること。たとえば次の取り方はすべてしない。
- User-Agent を変える（curl の `-A` でブラウザのふりをする、など）
- クローラー（検索エンジンの巡回プログラム）を名乗る
- キャッシュや保存版（検索エンジンのキャッシュ、Wayback Machine などの保存版、ミラー）で制限を回る
- 確認画面（Cloudflare など）をくぐる、cookie を作って通る
論文の公開ライセンスが開いていても同じ。**PDF は文字を抜く前に「テキスト抽出を許可しない」設定かを確かめ（pdfminer の PDFDocument の is_extractable）、その設定なら文字を抜かない**（CLAUDE.md「refs の書き方」。tools/quote_check_pdf.py と同じ扱い）。**一度でもしてしまったら、使わなかったとしても報告の冒頭に書く。**

対象の問題は、指定されたテキストファイルに1問ずつ出してある（Q=設問、★=正解、E=explanation、D=detail、N=note、U=画面に出る未確認の注記、R=refs）。

## 各問でやること（この順で）

0. **後の時代への影響を書いた文を最初に拾う。**「響き合う」「流れ込んだ」「受け継がれた」「今も生きている」「再評価された」「〜に影響を与えた」「〜の出発点になった」「研究が増えている」「〜とも通じる」の類。
   その関係（誰が誰を受けた・批判した・再評価した）を、基準の典拠が書いているかを確かめる。書いていなければ「支える典拠が見つからない」と書く。
1. **本文（E と D）の数字・年・逸話・直接の引用を一つずつ拾い**、既存の refs（R）が支えているかを見る。R の説明欄だけで判断せず、必要なら URL を実際に開いて確かめる（説明欄が中身とずれていることがよくある）。
   支えていないものは、基準の典拠を探して開き、支えるかを確かめる。
   **資料どうしが割れているときは、割れていることと、どの資料が何と書いているかを書く。**
2. **原典の箇所を示しているもの**（{{原典の箇所の例}}など）は、**原文か、その箇所を引く基準の典拠を開いて、その番号がその内容を指しているかを確かめる**。
   **訳書の章番号と原書の章・節が違うことがある。**両方が分かれば両方を書く。
   **引用で、訳によって言い回しが違うもの**は、どの訳の文言かを書く。
3. 正解の選択肢（★）の決め手を支える refs が1本だけ（または無い）なら、**2本目（無ければ2本）**を探す。
4. N に「確認できていない点:」、または U があれば、典拠で閉じられるかを調べる。
5. **この棚で特に見ること：**{{この棚で特に見ること}}

## 基準の典拠（これ以外は使わない）

- SEP（plato.stanford.edu）、IEP（iep.utm.edu）、Routledge Encyclopedia of Philosophy（rep.routledge.com。**無料で公開している範囲だけ**。ログインや購読が要る部分は開かない。2026年9月25日に足した）
- 公有の原典と正規の公開元：**著者の没年と刊行年から公有と分かるもの**だけ。この棚では、{{公有の原典}}。**{{全文サイトを使わない著者}}の原典の全文を載せたサイトは使わない**（箇所の確認は SEP・IEP・査読論文が引く頁、J-STAGE の論文の引用で行う）
- 査読誌の論文（書誌と DOI）、大学の機関リポジトリ、J-STAGE、版元の頁（本の抜粋なら可）、著者や遺稿管理者が自ら公開しているもの
- **使わない**：Wikipedia・Wiktionary、引用句サイト、ブログ、まとめサイト、Britannica と Routledge Encyclopedia of Philosophy 以外の百科事典サイト、grokipedia、monoskop、library genesis の類、講義ノートや授業の頁の PDF、コトバンク、権利者の許可なく本を丸ごと載せたサイト
- **置き場所で判断する**（本文が取れても、無断転載のサイトは使わない）

## 返答の形（1問ずつ）

```
### qNNN
- 影響の文「（本文の該当句をそのまま）」
  - 判定: 既存 refs が支える / 新しい典拠が支える / 支える典拠が見つからない / 典拠と食い違う
  - 典拠: URL — 箇所
  - 引用: "（開いたページから一字一句そのまま写した英文など。30〜60語程度）"
- 主張「（本文の該当句をそのまま）」
  - 判定・典拠・引用（同上）
- 原典の箇所番号「（本文の番号）」: 合っている / 違う（正しくは〜）— 開いた原文 URL と引用
- 正解の2本目の候補: URL — 何を確認したか（引用を添える）
- note の未確認・U: 閉じられる / 閉じられない（理由と典拠）
- 食い違い・気づいた点:（本文が典拠とずれている箇所、R の説明欄が中身と合っていないもの、リンク切れなど。無ければ「なし」）
```

**引用は必ず、実際に開いたページから写すこと。記憶で書かない。開けなかったページは「開けなかった」と書く。**
**WebFetch はページを小さなモデルで要約して返すので、原文に無い文が引用の形で混ざることがある。**引用は「一字一句そのまま」と指定して取り、どのページのどの節かを書く（書き込む側が、取り直した原文で照らし合わせてから refs に書く）。
**見つからないときは「見つからない」と書く。推測で埋めない。**
返答は日本語でよい（引用は原文のまま）。
