# Wikipedia を refs にしている204問の洗い出し【1】区分と一覧

**対象**：`q.source.refs` に `wikipedia.org` を含む問題。**【1】の実測で204問・231件**（2026年9月21日）。
**【2】で2問を処理したので、いまは 131問・144件**（下の「処理したもの」を見ること）。
**wikisource は含めない**（原典の本文であり、出典の基準の内側にある）。

**【1】でやったこと**：231件を1件ずつ、**Wikipedia が実際に何を支えているか**に照らして区分した。

**出典の基準は CLAUDE.md「refs の書き方」にある**（SEP・IEP、無ければ原典と定評ある二次資料）。
**全件を差し替えるのではなく、Wikipedia だけが支えている主張に絞る**という方針も既に決まっている。

## 区分の付け方

**refs の本数では決めていない。**1件ずつ、その Wikipedia が説明欄で「何を確認した」と書いているかを読み、
**同じ主張を他の refs が支えているかどうか**で付けた。

| 区分 | 中身 | 扱い |
|---|---|---|
| **(a)** | **他の refs がその主張を支えている** | **Wikipedia を外すか残すかだけ。**裏取りは要らない |
| **(b)** | **Wikipedia だけがその主張を支えている** | **SEP・IEP など基準の典拠で裏を取る対象** |
| **(c)** | **判断が要るもの** | 下の「(c)」を見ること |
| **対象外** | **支えているのが刊行年・原題・英訳年だけ** | **慣行の内側として扱う。**生没年と同じ線 |

**他の refs があっても (b) になる場合が多い。**Wikipedia の refs は
**刊行年・成立事情・受容史・語の来歴・具体例**といった、SEP や IEP が扱わない事実を支えていることが多く、
**同じ問題に SEP があっても、その SEP は別の主張を支えている。**

**対象外の線は「書誌だけか」で引く。**生没年の引用行が慣行の内側であるのと同じ理由で、
**刊行年・原題・英訳年だけを支えている ref は裏取りの対象にしない。**
**人物の同定を支えているものは対象外にしない**（q030 は「Gustav Emil Mueller が G.E.ムーアとは別人」という
同定であって書誌ではないので (b) に置いた）。

**他の ref も基準外のものは (b) として扱う。**q494・q499・q501・q511・q554 は Wikipedia 以外の ref もあるが、
**それが grokipedia・goodreads・個人サイトで基準を満たしていない。**Wikipedia を外すと支えが無くなるため、
