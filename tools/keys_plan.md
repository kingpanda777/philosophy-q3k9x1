# 既存47件の `keys` の片づけ計画【1】型分けと一覧

**対象**：`q.keys` に付いているが、その問題の本文（設問文・選択肢・explanation・detail）に
その語形が一度も出ない47件。**実測で47件・42問・46語**（2026年9月21日）。

**この段でやること**：47件を型ごとに分け、1件ずつ扱いを決めて書き出す。
**`questions.js` は変更していない。**次の段（【2】）で、ここで決めたとおりに直す。

**規則は CLAUDE.md「道具が keys 全部の語形も検査する」の節にある。**
そこの(b)（`check_keys` が全問の `keys` を見る）は、**この47件を片づけてから有効にする。**

## 方針（型ごとの扱いを決める前に、先に決めたこと）

**1. 扱いは「その語が、その問題の主題かどうか」で決める。**

| | 扱い |
|---|---|
| **主題でない**（比較の相手側の語・背景・系譜の言及） | **`keys` から外す** |
| **主題である** | **本文に語を足す**（最小の追記で語形を合わせる） |

**なぜこの一本で決めるか。**CLAUDE.md の3型（相手側の語／中身はあるが語が無い／語形のずれ）は
**原因の分類であって、扱いの分類ではない。**同じ「語形のずれ」でも、
相手側の語なら外すのが正しく、主題の語なら足すのが正しい。
**原因で分けると、同じ型の中で扱いが割れる。**主題かどうかで分けると割れない。

**2. 外すのは、次の二つに当たらないときだけ。**

- **その語が、ほかのどの問題の `keys` にも残らなくなる**（鍵語タブから語が消える。既存の規則）
- **外すと、その問題の `keys` が空になる**

**後者はこの計画で足した歯止めである。**主題かどうかだけで切ると、
**q139・q493・q501・q521・q543・q559 の6問が `keys` ゼロになる。**
`keys` なしが正常な問題はあるが（CLAUDE.md の該当節）、
**それは「付ける語が無い」問題のことで、語があるのに落とした結果の空とは別である。**
この6問は外さず、本文に語を足す側へ回した。

**3. 足す先は `detail` を既定とし、余地が足りない問題だけ `explanation` にする。**
`explanation` には字数の型が無い。**detail の上限は370字。**

**4. 台帳の語形が合成形**（「AとB」型、括弧つき）**で、本文が分かれて出ているものは、この方針の外。**
外しても足しても不自然になるため、**個別に判断を付ける**（下の「型3」）。

**5. 本文に足すときは、初出併記（q303型）にする。**
**中身は元から本文にあるので、事実の追加にはならない。**新しい文は足さず、既存の一文へ織り込む
（q260・q582 で使った型）。

## 型3　台帳の語形が合成形で、本文は分かれて出る（7件）→ 個別に判断する

**「AとB」型、または括弧つきの語形。**本文には A も B も出ているが、**つないだ形が出ない。**
**外すと語が消えるか `keys` が空になり**（7件とも、他にこの語を持つ問題が無いか、主題そのもの）、
**足すと不自然な連結形を本文に置くことになる。**だから方針の外に出した。
