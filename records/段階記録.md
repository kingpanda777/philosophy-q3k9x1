## 新規追加の打ち止め（2026年9月12日〜9月14日。役割を終えた）

**なぜ打ち止めたか。**完成の定義の項目は、どれも「いま何問・何人あるか」を数えて
片づける形をしている。**対象が増え続けていると、数えたそばから数が変わり、
どこまで片づいたのかが決まらない。**だから第五段階をもって対象をいったん固定した。
**禁止ではなく、完成の定義に到達するまでの一時的な措置である。**

**いつ役割が終わるか。**完成の定義の全項目が埋まった時点である。
**2026年9月14日に⑤と⑦が片づき、②〜⑧の7項目がすべて完了した**（①は運用へ移した）。
**固定しておく理由はここで無くなった。打ち止めは失効している。**

**以後の人物追加は禁止ではない。**足すかどうかは通常の判断で決めてよく、
**別途の許可や再開の宣言は要らない。**

**ただし、足すときは一式そろえること。**片方だけ足すと必ずどこかが古くなる。

| そろえるもの | 中身 |
|---|---|
| **`PHILOSOPHERS`** | `name`・`years`・`school`・`note`。生没年は `tools/years_src.json` に引用行も足す |
| **`PHIL_INTRO`**（`philosophers.js`） | `intro`・`thought`・`thought_src`・`works`・`checked`。**入れないと紹介の入口が出ない** |
| **鍵語の登録** | `keyterms.json` に語と読み → `q.keys` → `tools/keys_draft.json` → `index.html` の `KEY_YOMI` → `node tools/gen_key_owner.js` |

| **検査** | `node tools/check_phil.js` と `node tools/check_keys.js` を通す |
| **数え直し** | `node coverage.js` を走らせ、上の「進捗」の表を更新する |

| q583 | 政体の3類型が0問だった。q057 が「基準自体が政体によって違う」と触れるだけ |

**鍵語は4案から3語に絞った。**

- **「法の精神」は書名なので落とした。**書名は鍵語にしない方針（q246・q472、ベンヤミンの「パサージュ」）
- **徳・名誉・恐怖は「政体の原理」1語にまとめた。**別々に登録すると「徳」がアリストテレスの徳と衝突し、
  「恐怖」は一般語として誤検出する。**警告4語と同じ型である**
- 「三権分立」は「権力分立」と同義の別表記なので登録しない（規則2の部分文字列を増やさない）

**資料が割れた3件は書かなかった**（「資料どうしが割れたら、その項目を書かない」）。
生年月日（Wikipedia「18 January」／SEP「January 19th」）、官職を売った年（SEP 1725／Wikipedia 1726）、
刑事部を主宰した年数（SEP「for eleven years」だが1716→1725/26と合わない）。
**年 1689–1755 はどちらの資料でも一致するので `years` はそのまま採った。**

**`terms` は「権力」だけにし、「自由」は付けなかった。**
モンテスキューの「自由とは法の許すことをなしうる権利」は
TERMS「自由」の note の二分（邪魔がないことか、自ら法を課すことか）**のどちらでもない第三の読み**で、
1問だけ混ぜると二分が崩れる。**detail で触れるにとどめた。**

**q584 の detail 第3段落は、一方だけに寄らないように書き直した。**
中間権力論を貴族の擁護と読む見方（thèse nobiliaire）は古くからあるが、
**『ペルシア人の手紙』（1721年）は貴族を痛烈に批判しており、単純な自己弁護とは読まれていない。**
草稿では批判の側だけを書いていた。「『割れている』と書くだけでは足りない」の逆で、
**片側だけ書くのも同じ誤りである。**

## add_batch.js の入力の検査と規則の突き合わせ（2026年9月21日）

**⑩ terms・keys を空にしたとき note の「設計の記録」に理由があるかは、道具で見ないと決めた。理由の文面は書き手に任せ、道具で縛らない（空の一覧は出す）。**
